# CITE-seq：RNA–蛋白配对与细胞类型识别

## 数据与实践

公开PBMC约7,852个细胞、Stuart约33,454个细胞，处理RNA–蛋白条码配对、基因列统一、作者细胞标签与粗细层级映射。基于scMMT公开网络，采用来源TRAIN拟合的归纳式预处理，比较RNA输入下的跨研究细胞类型识别。

训练阶段可用配对蛋白与标签；部署阶段只输入RNA。实验比较hard/partial监督、叶类KD、父类KD和父类裕量约束，保留17、42、2026三个种子和两个迁移方向。

## 结果与解释

[双向结果表](../../results/citeseq_classification.csv)按固定9个共有细类报告macro-F1。hard双向均值约0.6360，父类KD约0.6362，提升很小；父类裕量约0.6309，未通过候选门槛。因此不把新增模块写成稳定改进。可保留的学习成果是数据配对、监督设计、复现适配、错误分解及负结果分析。

两个数据来源各只有一个生物学供者；Stuart的技术分管不是多个独立供者。两来源均为开发数据，不能据此宣称广泛泛化或原论文成绩复现。
