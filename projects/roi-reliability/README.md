# 连续测量ROI向未测区域外推的可靠性评估

## 实践内容

基于已有表达预测，比较集中与分散的测量布局，以及split conformal、区块CV+、加权校准等成熟对照。评价实际覆盖率、区间宽度与proper interval score，区分整体/逐基因和近/远区表现。

## 独立布局确认

在额外14位胰腺癌患者上，沿封存协议比较50个标注的两种布局。保守CV+的分散减集中远区覆盖率为+0.0532，患者bootstrap95%CI[0.0361,0.0729]，14/14患者方向为正。与此同时，分散布局区间更宽：width/oracle约1.432，集中约1.187。因此不能只看覆盖率宣称免费提高可靠性。

[完整确认汇总](../../results/independent_roi_layout.csv)。只读保留测试区；结论条件于共同3位源患者拟合，不是所有39位患者都做独立确认，也不是一个新校准算法。
