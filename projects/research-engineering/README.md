# 科研工程实践

- 大型图像/HDF5/AnnData处理、特征和条码顺序核验、文件哈希与配置溯源。
- Linux/SSH实验部署，双A100上的资源调度，按任务归属进行恢复，保留失败记录。
- 已完成预测独立封存，资源错误仅重试未完成部分；不把断线监控当成模型失败。
- 推理/训练优化保持统计目标和数值算式，区分计算工程修复与科学参数修改。
- 科学参数在实验前封存；结果后的修订明确标注，保留旧协议与旧结果。

展示版提供[只读GPU状态脚本](../../scripts/gpu_snapshot.py)、[数学自检](../../src/interval_math.py)、结果导出溯源。真实服务器任务控制器不在此仓库公开，避免将认证信息、机器路径与活动实验混入展示材料。
