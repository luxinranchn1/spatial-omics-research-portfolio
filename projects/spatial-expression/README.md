# 病理图像与空间表达预测：跨队列与少标注评估

## 问题

H&E图像预测空间表达在不同队列/平台之间迁移时，目标标注、模型选择和标注位置分别带来多少收益？

## 实践内容

- 处理公开Visium/Xenium空间数据与病理图像，核对条码、基因、物理坐标和图像特征的对应。
- 研究乳腺癌6位、肺癌14位、肾癌5位目标患者；各场景分别使用90、22、169个基因端点。
- 评估UNI2、Phikon-v2、Kaiko-L14；选块策略包含随机、空间覆盖、聚类覆盖、k-center、TypiClust和源模型不确定性。
- 对Ridge、TRIPLEX、DeepSpot进行公开代码适配与同协议比较；TRIPLEX模型×标注比较在乳腺癌/肺癌20位患者上补齐3个种子。
- 按患者隔离、使用空间区块与500μm缓冲带，保持比较的预算和测试区域一致；来源域拟合预处理。

## 已完成成果

- [模型×标注2×2表](../../results/model_annotation_2x2.csv)：肺癌Ridge从0.287提升到0.565，TRIPLEX＋同预算到0.583；标注与模型的增益具有场景和种子依赖。
- [多编码器表](../../results/encoder_annotation.csv)：用多个冻结编码器检验标注收益的稳健性。
- [选块策略表](../../results/selection_strategies.csv)：选块增益较小，聚类合并比较Holm校正p≈0.242，不能写成普遍显著胜出。
- [癌种筛查流程](../../results/cancer_screening_flow.csv)：公开可用性、患者数和门槛不足的场景也保留记录。
